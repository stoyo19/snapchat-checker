# Snapchat Username Checker

A fast and simple tool to check the status or availability of Snapchat usernames.

## Features

* **Single Input Mode:** Enter any Snapchat username to check its status instantly.

## Usage
1. Install dependancies (installer.bat)
2. Run the application (start.bat).
3. Enter the target username when prompted.
4. View the result.

## Requirements

* Python 3.13 or higher
* Required dependencies (Run installer.bat)

## Disclaimer

This tool is intended for educational and personal availability-checking purposes only. Ensure compliance with Snapchat's Terms of Service.
